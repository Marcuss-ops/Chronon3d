# Iconify preview scene contract

- Subject: four Lucide SVG icons downloaded from Iconify: bus, lightbulb, thermometer, and chart.
- Composition: one row of four icons centered in simple dark cards on an 854×480 canvas. Fixed straight-on camera; no motion.
- Layers: dark card background and each icon as a separate imported SVG layer.
- Must not appear: logos, titles, interface chrome, extra decorative subjects.
- Preview approval evidence: one software-rendered 854×480 PNG showing all four distinct SVG assets with their explicit stroke colors.
