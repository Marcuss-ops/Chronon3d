# Lucide SVG samples via Iconify

Downloaded directly from the Iconify public API; no API key is used. `SOURCES.json` records each endpoint, color variant, dimensions, and license. The plain files preserve Iconify defaults; the `*-128.svg` files have explicit 128×128 dimensions and explicit stroke colors for stable previews.

Icon set: Lucide, ISC license. Attribution and license: https://github.com/lucide-icons/lucide/blob/main/LICENSE

A four-icon raster reference is available at `C:/Users/pater/OneDrive/Documenti/Chronomotion/MP4/iconify_samples_preview.png`; it was rasterized from the explicit-size SVG files with FFmpeg and composed into a contact image. `iconify_preview.plan.json` and `ICON_PREVIEW_CONTRACT.md` describe the separate Chronon import preview scene.
