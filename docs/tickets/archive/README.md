# Archived tickets

Tickets that are closed, resolved, removed or otherwise inert. They are kept
because they carry the reasoning and the evidence behind a decision, not
because anything in them is still pending.

Rules:

- Nothing here is authoritative for the present state. For that, read
  [`../../CURRENT_STATUS.md`](../../CURRENT_STATUS.md).
- Nothing here is re-opened. If the problem returns, open a new ticket in
  `../` that links back to the archived one.
- A referenced ticket must keep resolving from the live indexes; when a file
  moves here, update [`../../FOLLOWUP_TICKETS.md`](../../FOLLOWUP_TICKETS.md)
  and [`../../CURRENT_STATUS.md`](../../CURRENT_STATUS.md).

See [`../../INDEX.md`](../../INDEX.md) for the documentation map.
